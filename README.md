# CropGuard AI 🌱

AI-Powered Crop Disease Detection and Management System.

## Overview

CropGuard AI uses computer vision and machine learning to
detect crop diseases from plant images and provide
disease management and prevention information.

## Planned Features

- Plant disease image classification
- Confidence score
- Disease information
- Disease management recommendations
- Environmental risk assessment
- Web interface
- Model explainability

## Tech Stack

- Python
- PyTorch
- Torchvision
- Scikit-learn
- Streamlit
- FastAPI
